# AppManager Project Assurance Library

> **Status:** Active library index
>
> **Normative product effect:** None.

This directory contains retained verification and evaluation evidence. Its contents may identify defects, findings, recommendations, or reconciliation evidence, but they do not independently amend the normative product-document hierarchy.

- `audits/` contains formal conformance and verification audits.
- `reviews/` contains architecture/documentation reviews and investigations.
- `reconciliations/` contains source-comparison and reconciliation records.

For current project state and authorised work, begin with [`../README.md`](../README.md).
