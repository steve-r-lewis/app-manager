# AppManager Project History Library

> **Status:** Active library index
>
> **Normative product effect:** None.

This directory preserves completed project-management activity and transition history. Historical records remain available for provenance and institutional memory but are not current project directives.

- `handovers/` contains superseded session/programme continuation records.
- `closeouts/` contains completed programme/work-package closeout evidence.
- `programmes/` contains completed plans, inventories, correction overlays, migration records, and status records retained to explain how the current state was reached.

Imperative wording inside a historical record applies to the baseline and lifecycle state that record captured; it must not be treated as a current instruction without confirmation from [`../README.md`](../README.md).
