# Raising Issues

Found a bug? Have a feature request? Here is how to let us know.

## Reporting Bugs

Please open a GitHub Issue with the following template:

1.  **Description**: What went wrong?
2.  **Steps to Reproduce**:
    * Run command `...`
    * Select option `...`
3.  **Expected Behavior**: What should have happened?
4.  **Actual Behavior**: What actually happened?
5.  **Environment**:
    * OS: (Windows/Mac/Linux)
    * Node Version:
    * App Manager Version:

## Feature Requests

We love new ideas! Please describe:
1.  **The Problem**: What friction are you experiencing?
2.  **The Solution**: How would you like the tool to handle it?
3.  **Domain**: Which domain does this belong to (Git, Nuxt, Utils)?
